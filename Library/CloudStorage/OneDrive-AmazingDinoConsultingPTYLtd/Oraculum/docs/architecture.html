Key Formulas

Year Pillar (after Li Chun check)

// Reference: 1984 was Jia-Zi (甲子) year cycleYear = year - 1984 stemIndex = (cycleYear % 10 + 10) % 10 branchIndex = (cycleYear % 12 + 12) % 12

Month Stem - Five Tiger Method (五虎遁)

// HPA-BA Formula baseStemIndex = (yearStem.rawValue * 2 + 2) % 10 offset = (monthBranch - Tiger) % 12 monthStem = baseStemIndex + offset

Day Pillar - Julian Day Number

// JDN 11 was Jia-Zi (甲子) cycleIndex = (JDN - 11) % 60 dayStem = cycleIndex % 10 dayBranch = cycleIndex % 12

Hour Stem - Five Rat Method (五鼠遁)

// HPA-BA Formula baseHourStem = (dayStem.rawValue * 2) % 10 hourStem = baseHourStem + hourBranch.rawValue

🎯 Luck Pillars (大运) - Gender-Based Calculation

Direction Determination Rule

The direction of Luck Pillars depends on Year Stem Polarity and Gender:

Year Stem Gender Direction Chinese
Yang (甲丙戊庚壬) Male → Forward 顺行
Yang (甲丙戊庚壬) Female ← Backward 逆行
Yin (乙丁己辛癸) Male ← Backward 逆行
Yin (乙丁己辛癸) Female → Forward 顺行

Code: Direction Determination

func determineDirection(yearStem: HeavenlyStem, gender: Gender) -> LuckDirection { let isYangYear = yearStem.polarity == .yang switch (isYangYear, gender) { case (true, .male): return .forward // 阳年男顺行 case (true, .female): return .backward // 阳年女逆行 case (false, .male): return .backward // 阴年男逆行 case (false, .female): return .forward // 阴年女顺行 } }

📊 Scoring System - 7-Level Evaluation

Scoring Levels (Priority Order)

1
Year Breaker (岁破) Detection
Day Branch clashes with Annual Branch → -40 penalty for constructive activities, +10 bonus for destructive
2
Personal Clash / Fan Yin (犯寅)
Day Branch clashes with User's Day Master Branch → INSTANT FAIL (only fail condition)
3
Day Officer Contextualization
Officers compromised during Year Breaker → "Deceptive Open" instead of "Open"
4
Lunar Star Processing
Heavenly Virtue (天德) nullifies minor negative stars; major inauspicious stars still apply penalties
5
Non-Critical Clashes
Month clashes, year clashes (except Fan Yin), Three Penalties, Six Harms
6
Useful God (喜用神) Resonance
Day's element supports User's Useful God → bonus; clashes → penalty
7
Branch Combination Analysis
Three Harmonies (三合), Three Meetings (三会), Six Combinations (六合) → bonuses
