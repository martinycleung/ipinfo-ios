# LinkedIn Connection Request Template

## Connection Message (300 character limit)

Hi {{contact_first_name}}, I noticed {{company_name}} is {{buying_signal_brief}}. I help organisations implement AI agents securely. Would love to connect and share insights on {{industry}} automation trends.

## Alternative Messages

### Version A - Mutual Interest
Hi {{contact_first_name}}, your work at {{company_name}} on {{specific_project}} caught my attention. I specialise in AI implementation for {{industry}}. Would be great to connect.

### Version B - Value Offer
Hi {{contact_first_name}}, I've been researching {{industry}} AI trends and thought you might find it valuable. Happy to share insights - let's connect!

### Version C - Direct
Hi {{contact_first_name}}, I help {{industry}} companies implement AI agents with a security-first approach. Thought there might be synergy with {{company_name}}'s direction.

## Variables
- {{contact_first_name}} - Contact's first name
- {{company_name}} - Company name
- {{buying_signal_brief}} - Short signal description
- {{industry}} - Their industry
- {{specific_project}} - Something they're working on

## Follow-up Message (after connection accepted)

Thanks for connecting, {{contact_first_name}}!

I'd love to learn more about {{company_name}}'s automation journey. Would you be open to a quick 15-minute chat? No pitch - just curious about your priorities this year.

Let me know what works for you.

Best,
Martin
