## App Description

**Short Description (Promotional Text - 170 chars):**
Instantly look up any IP address or domain name. Get location, organization, ASN, and more. View results on an interactive map.

**Full Description:**
IP Info is a powerful yet simple tool for looking up information about any IP address or domain name. Whether you're a network administrator, developer, security professional, or just curious about an IP address, IP Info provides instant access to detailed information.

**Key Features:**

• **IP Address Lookup** - Enter any IPv4 or IPv6 address to get detailed information including location, organization, and ASN.

• **Domain Name Resolution** - Enter any domain name (like google.com) and instantly see its IP address along with all associated information.

• **My IP Address** - With one tap, discover your current public IP address and its associated details.

• **Interactive Map** - View the geographic location of any IP address on an interactive map.

• **Detailed Information** - Get comprehensive data including:
  - City, Region, and Country
  - Organization and ASN
  - Timezone and Currency
  - Coordinates

• **Search History** - Quickly access your recent lookups without retyping.

• **Copy & Share** - Easily copy IP addresses or share complete lookup results.

• **Privacy Focused** - Your search history is stored only on your device. No account required.

**Perfect for:**
- Network administrators troubleshooting connectivity
- Security professionals investigating suspicious IPs
- Developers testing geolocation features
- Anyone curious about IP addresses and domains

Download IP Info today and start exploring the internet!
